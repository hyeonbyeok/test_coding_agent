사용자가 "이렇게 해줬으면 좋겠다"고 관례를 제안할 때, 그 자리에서 새 규칙을 만들지 말고
**기존에 같은 것을 정하는 규칙이 있는지 먼저 찾는다.** 있으면 새로 만들지 않고 기존 것을 따른다.

**Why:** 사용자는 자기가 제안하는 것이 이미 정해져 있는지 모르는 상태로 말할 때가 많다.
확인 없이 새 규칙을 얹으면 같은 것을 정하는 규칙이 두 개가 되고, 나중에 충돌한다.
(2026-08-21, README 배치 규칙을 요청하며 직접 이렇게 요구했다 —
 확인해 보니 GSD `gsd-doc-writer` 에 이미 "README·CONTRIBUTING 은 루트, 나머지는 docs/,
 monorepo 는 per_package" 규칙이 있었고 요청과 일치해서 새 규칙을 만들지 않았다.)

**How to apply:** 도구 설치물(GSD 등) 안까지 grep 해서 찾는다. 찾은 뒤 세 갈래로 처리한다 —
일치하면 그대로 쓰고 사용자에게 "이미 있다"고 알린다 / 어긋나면 양쪽을 보여주고 고르게 한다 /
없으면 그때 만든다. 만들 때도 T0(`CLAUDE.md`) 예산을 확인하고 최소 줄 수로 넣는다.
